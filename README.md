# 🦠 COVID-19 Pandemic Analysis

## 📌 Project Overview
This project analyzes COVID-19 pandemic data to understand the spread of the virus, identify trends, and explore the impact of the pandemic across different regions. 

The project uses Python for data cleaning, exploratory data analysis (EDA), and data visualization to extract meaningful insights from the dataset.

## 🎯 Objectives
* Analyze COVID-19 cases, deaths, and recoveries.
* Explore pandemic trends over time.
* Compare COVID-19 statistics across countries or regions.
* Create visualizations to communicate important patterns.
* Practice data cleaning and exploratory data analysis.

## 🛠️ Technologies Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook
* **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/roshan7-hub/covid-19-pandemic-analysis.git
```

### 2. Navigate to the project directory
```bash
cd covid-19-pandemic-analysis
```

### 3. Create a virtual environment (optional)
```bash
python -m venv venv
```

*Activate it on Windows:*
```bash
venv\Scripts\activate
```
*Activate it on macOS/Linux:*
```bash
source venv/bin/activate
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the analysis
Open the notebooks in the `notebooks/` directory using Jupyter Notebook or JupyterLab.
```bash
jupyter notebook
```
